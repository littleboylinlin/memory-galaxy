## 对原始目标的结论

| 原始目标                             | 结论             | 具体边界                                                                                       |
| ------------------------------------ | ---------------- | ---------------------------------------------------------------------------------------------- |
| 通用、可扩展的记忆星盘               | 已实现且通过测试 | MGP 1.0 兼容、1.1、扩展字段、JSON / JSONL；未知版本拒绝                                        |
| 稳定 ID、增量、冲突、删除与恢复      | 已实现且通过测试 | 不按缺失猜测删除；恢复墓碑需处理冲突；snapshot 按 ID 合并，不代表替换                          |
| 多来源映射与追溯                     | 已实现但存在限制 | 保留声明、原 ID、引用、追溯与来源冲突；不能独立认证导出方身份或其 `full` 声明                  |
| 关系准确性                           | 已实现但存在限制 | 仅保存输入或用户明确创建的关系，保留 explicit / inferred / rule；不保证来源本身的判断正确      |
| 导入、编辑、保存、导出、备份恢复链路 | 已实现且通过测试 | 完整备份包含图谱、历史与视图，普通 MGP 导出只包含图谱；均有严格资源上限                        |
| 布局、动画、缩放、拖动、搜索、详情   | 已实现且通过测试 | 布局与导入使用 Worker，失败时可继续浏览列表；密集星图采用绘制预算，不删除底层数据              |
| 移动端适配与键盘操作                 | 已实现但存在限制 | 桌面和手机视口的 Chromium、Firefox、WebKit 回归；不代表真实手机认证                            |
| 输入安全与本地处理                   | 已实现且通过测试 | 文本不执行，危险对象键、无效引用、异常大小被拒绝；无模型调用和记忆上传路径                     |
| 本机保存与异常恢复                   | 已实现但存在限制 | 事务版本校验、失败保留内存、损坏缓存保护、快照撤销；浏览器配额、清理与磁盘故障仍由环境决定     |
| 长期维护                             | 已实现但存在限制 | 协议、Schema、契约测试、四浏览器 CI、构建清单和发布检查齐备；不承诺未来浏览器行为不变          |
| Pages 与 main 一致                   | 由发布工作流验收 | 必须通过 main 检查、部署、线上清单与资源 SHA-256、核心浏览器冒烟；不能仅凭本地构建判定发布成功 |

本轮没有已确认但未修复的阻断性功能问题。尚未达到的可选能力包括备份加密、JSONL 流式读取、协作合并和墓碑压缩；它们不属于当前版本承诺的功能。不能把这些能力记为已完成。

## 测试与发布证据

单元与协议用例集为 112 项；新增回归曾在旧实现上实际复现来源误挂、空删除数组校验问题。浏览器用例集为每项目 54 项，覆盖桌面 Chromium、手机视口 Chromium、桌面 Firefox、手机视口 WebKit。具体通过状态、重试情况和日志以该提交的 [GitHub Actions](https://github.com/littleboylinlin/memory-galaxy/actions) 为准；发布还独立执行桌面与手机 Chromium 共 6 项冒烟检查。

合成测试使用 3 个来源、402 条记忆、2,028 条具有稳定 ID 的关系，并以计数器生成 18 个集合标记。它只参考 Records / Relations 的结构，所有正文、来源引用和 ID 都是虚构的。单元测试覆盖导入、手动编辑、删除、拒绝旧快照复活、撤销和备份精确恢复；浏览器用例实际导入 JSONL，保存后重新打开，并从空工作区恢复完整备份，逐项比较导出的图谱。原有 10,000 节点 / 9,999 关系的导入、搜索与完整导出回归继续保留。

本轮本地独立测试浏览器受到进程 socket 权限限制，未将启动失败计为用例通过。跨浏览器自动化在 GitHub 执行；另通过可用浏览器查看实际星盘与核心交互。没有为通过测试降低平台权限或修改浏览器安全设置。

## 剩余限制与严重程度

| 程度 | 限制                                       | 实际影响                                                                  |
| ---- | ------------------------------------------ | ------------------------------------------------------------------------- |
| 中   | 本机数据、快照和备份未加密                 | 获取此浏览器存储或备份文件的人可读到内容；`sensitive` 仅为标记            |
| 中   | 升级前已打开的旧版本页面没有事务版本校验   | 升级后应刷新旧页面；新旧代码并存时不能约束旧代码的写入                    |
| 中   | 浏览器存储配额、回收和用户清理             | 本机保存不代替独立备份；没有服务端副本                                    |
| 低   | 非流式 JSONL、历史与图谱复制存在主线程开销 | 导入 12 MiB、完整备份 48 MiB；快照最多 12 份 / 16 MiB，不保证协议上限帧率 |
| 低   | 来源与关系的外部真实性未认证               | 系统保留证据，不替导出方背书或猜测未知事实                                |

当前环境无法验证真实 iOS / Android 设备、协议上限图谱的完整交互帧率、所有系统剪贴板实现、浏览器崩溃或断电时的实际磁盘持久化。上述范围没有标为通过。
