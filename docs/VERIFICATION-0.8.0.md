# Memory Galaxy 0.8.0 验收

基线为正式发布的 `v0.7.0`（`9b54424e43177d23a8466242670b73b1d2a77381`）。三平台继续使用同一套 Electron、前端和 SQLite 代码。测试使用合成资料。

## 数据保护与兼容性

- 完整备份和新资料库在同一文件系统内暂存。写入失败、进程中断或同名目标竞争时，目标路径不会出现半成品，也不会覆盖已有文件。
- SQLite 回滚日志保留 `DELETE` 模式和 `synchronous=EXTRA`。macOS 额外启用 `fullfsync`。测试覆盖强制终止持有回滚日志的写入进程、SQLite 页容量失败、无写入权限、损坏数据与记录校验、资料库复制冲突。
- Linux 的空间测试使用独立 2 MiB 文件系统，验证备份写入收到 `ENOSPC`，SQLite 替换中止，已提交资料及已有备份仍可读。
- 默认明文资料库继续使用原有 SQLite 结构。加密副本写入新目录，明文库可直接切回。加密备份使用独立扩展名，解密后校验原有完整 JSON 备份及其 SHA-256。损坏密文、错误密码或过期预览会阻止恢复。
- 兼容 v0.7.0 完整备份、网页迁移包和旧版工作区备份。MGP 1.0/1.1 与主题包格式及稳定 ID、关系、来源和删除标记规则沿用现有校验。

## 发行包验收范围

| 平台                            | 使用的发行包       | 自动化验收                                                                                                                                            |
| ------------------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows Server 2025 x64         | NSIS               | 校验正式 0.7.0 安装程序的 SHA-256，离线安装并实际生成资料及备份，再覆盖安装新版本，逐项比对默认资料库、回顾和主题包。卸载后核对 SQLite 文件 SHA-256。 |
| macOS 15 Apple Silicon 和 Intel | 两份架构各自的 DMG | 核对 Mach-O 架构及 ad-hoc 签名，从磁盘映像复制应用并在离线隔离中运行。移除应用后核对资料库。                                                          |
| Ubuntu 22.04 x64                | AppImage 和 deb    | 离线安装、执行和清除 deb，运行 AppImage 的 extract-and-run 模式。核对两份发行包共用默认资料库及移除后的文件完整性。                                   |

各发行包执行应用内离线导入、保存、强制退出重开、非 ASCII 路径、加密复制、错误密码、损坏文件、旧版备份预览和回退备份用例。原生对话框测试检查参数并替换用户选择结果，后续文件操作使用发行包中的应用。实际通过的组合见对应发布提交的 Actions。

Windows 实机、实体 Mac、实体 Linux、实体断电与存储设备缓存、原生文件选择器人工点选、AppImage FUSE 以及下载后 Gatekeeper 交互需要单独验收。进程强制终止和受控磁盘写满属于故障模拟。

Windows 签名需要可用的代码签名证书及签名时间戳。macOS 公证需要 Developer ID Application 证书、Hardened Runtime、签名时间戳和 Apple 公证凭据。当前配置生成未签名的 Windows 安装器及 ad-hoc macOS 应用。参考 [Microsoft SignTool](https://learn.microsoft.com/en-us/windows/win32/seccrypto/signtool) 和 [Apple 公证要求](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。
