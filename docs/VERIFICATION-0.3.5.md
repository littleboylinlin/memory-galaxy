## 回归范围与结果入口

单元、协议、生命周期和构建测试共 **153 项**，新增 30 项。浏览器套件由每项目 64 项增至 **70 项**，四个现有项目共 280 项；新增 6 项覆盖旋转、冲突、中文错误和快照恢复，并输出竖屏、横屏及冲突审查截图供检查。实际执行结果以本次 PR 的 Checks 和 Actions 日志为准，测试数量不代替执行结果。

原有保存失败、事务完成反馈、重复保存、并发覆盖保护、刷新恢复、同名标题与关系 ID、10,000 节点图谱、402 条记忆 / 2,028 条关系 JSONL 备份回归继续运行。测试数据均为虚构数据，不是私人记忆或真实账户导出。

本地可执行源码、格式、单元和完整构建检查。此环境未安装 Playwright 对应浏览器；使用已有 Chromium 后又在启动阶段遇到 `socket() failed: Operation not permitted`。该次浏览器运行失败 1 项、5 项未执行，没有执行页面步骤，不计为功能验证通过；完整矩阵通过仓库现有 GitHub Actions 执行。

合并后按现有流程构建并发布 0.3.5，核对线上 revision、27 个公开文件的 SHA-256，并执行线上 Chromium 部署冒烟检查。发布是否成功以 main 对应的 Actions 结果和线上构建清单为准。

首次 main 发布流程中，Firefox 的 Ubuntu 依赖从 Azure 镜像下载过慢，约 20 分钟后作业取消，未进入页面测试。重试仍停留在依赖安装阶段，因此 CI 在浏览器安装前移除运行器镜像列表中的 Azure 项，沿用列表中已有的 Ubuntu 官方 HTTPS 归档及安全镜像；保留签名校验、依赖安装、四组浏览器和发布门槛。列表格式依据 [GitHub 运行器的配置脚本](https://github.com/actions/runner-images/blob/main/images/ubuntu/scripts/build/configure-apt-sources.sh)，不修改应用或协议内容。

## 未验证范围

未重写旧快照的标题或既有开发历史。远端开发分支由维护者自行删除。
