# 源码与数据路径审计

审计基线：`7805234f7b2057dad2425115f9e0a50785a44795`。范围包括原有源码、协议与示例、导入路径、本机缓存、Canvas 运行路径及现有测试。采用源码审阅、协议契约测试和浏览器验证；本文不代表独立渗透测试或所有设备的性能认证。

## 协议与导入阶段

| 位置                     | 原有问题                                                         | 本轮处理                                                                                 |
| ------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `web/app.mjs` 导入入口   | 直接合并，同 ID 字段被覆盖，没有确认边界                         | 导入移至 Worker；预览后一次性应用；取消、错误与未解决冲突保持原图                        |
| 示例与本机缓存           | 默认示例会和第一次用户导入合并；保存示例后刷新也可能混入         | 首次确认从空工作区导入；识别原样保存的示例；旧缓存不被自动覆盖                           |
| `web/mgp.mjs` 版本与更新 | 只有 1.0 校验和简单 upsert，没有删除及冲突流程                   | 1.0 兼容迁移、1.1、显式删除、墓碑、来源追溯、逐项或批量冲突处理                          |
| Schema 与运行时校验      | Schema 与运行时的长度、日期、枚举约束不一致；未知字段静默忽略    | 更新 Schema；增加共享结构契约测试；1.1 拒绝未知字段，旧版额外字段保存在 extensions       |

| 资源限制                 | 只限制本批节点和边，累积合并可突破上限；粘贴输入没有同等字节限制 | 输入与结果均限制 UTF-8 字节数；检查累计节点、关系、墓碑、来源与嵌套深度                  |
| 文本与对象边界           | 文本显示采用 textContent / Canvas，原型属性键未明确限制          | 保留文本显示，拒绝危险属性名与非 JSON 数值；加入内容安全策略、原型污染及网络请求回归测试 |
| `web/prompt.mjs`         | 产品导出提示词同时保存于模块和文本文件，容易不同步               | 仅保留协议目录中的产品提示词；按钮按需读取同源文本，剪贴板不可用时支持手动复制           |
| 来源与覆盖范围           | 合并根来源仅为 merged，缺少逐项来源；full 可能被误当作事实       | 记录来源与引用；保留旧数据来源未知状态；来源声明变化进入冲突；full 始终标注未验证        |
| 重置和缓存错误           | 切回示例可能替换未导出的当前图谱；清除缓存异常未处理             | 替换用户图谱前确认；缓存异常有反馈并保留内存数据                                         |

## 协议阶段的性能观察

原有力导向循环按空间网格找邻居，但初始节点集中在很小区域，同一网格内仍可能出现近似二次方的成对计算。Canvas、布局和拖动逻辑本轮继续沿用，没有把协议数据上限当作渲染性能承诺。

协议侧已将解析、严格校验和差异规划移出主线程。批量节点删除按端点索引查找关联边，避免每删除一个节点就扫描所有关系。冲突列表按每页 30 项显示，本批内容预览限制展示条数，实际校验覆盖完整批次。输入过大或处理超时会停止，确认按钮保持不可用。

在本次 Node.js 24.22.1 容器中，单轮合成数据测量为：10,000 个节点、0 条边、997,886 字节输入；解析与校验约 39.6 ms，空工作区差异规划约 67.7 ms。该测量不包含浏览器消息复制、布局、绘制或设备差异，不能推导大图帧率。

## 验证范围

协议测试覆盖版本兼容、JSON / JSONL、错误定位、稳定身份、来源与墓碑、逐项决策、日期及 revision 比较、重复回放、累计上限、原型属性及输入不可变性。Schema 测试覆盖两种版本、示例、无效字段、日期、删除记录和产品导出格式。

浏览器测试覆盖桌面与手机视口的粘贴、文件和拖放、确认前不修改数据、取消与焦点返回、逐项及批量冲突、删除联动、旧缓存、示例隔离、恶意文本、覆盖声明、大小限制和剪贴板回退。

本机浏览器运行环境与实际执行结果记录在 PR 的测试说明中；未执行的浏览器或平台不计入通过范围。

## 星图与工作区阶段

基线：`492f0930be4165a5fb5382b706df1123c50b17db`。继续沿用 MGP 校验、增量合并与导入预览，将原有 Canvas 交互拆分为布局、渲染和工作区模块。

| 路径                                     | 问题与处理                                                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `web/layout.mjs`、`layout-worker.mjs`    | 密集网格逐对排斥改为单元聚合；按真实边计算连通分组，布局不新增协议关系；迭代与消息均有边界                                     |
| `web/sky.mjs`                            | 布局移出主线程；视野裁剪、绘制数量与标签预算、密集视图抽样、按需重绘；拖拽固定、平移缩放与关系高亮；布局失败明确降级           |
| `web/workspace.mjs`                      | 编辑与删除复用 MGP 校验和墓碑；稳定身份、来源保留与本机来源名称冲突处理；图谱替换前快照、撤销及严格备份校验                    |
| `web/storage.mjs`                        | IndexedDB 事务保存；保留旧缓存迁移；保存异常不丢弃内存图谱；多页面变化提醒和覆盖确认                                           |
| `web/backup-ui.mjs`、`backup-worker.mjs` | 完整备份独立入口；大小、结构、图谱、历史和坐标校验；预览确认、取消与延迟读取隔离                                               |
| `web/import-ui.mjs`                      | 发现大单行文本直接填入浏览器控件可能导致排版卡顿或进程崩溃；粘贴前接收大文本，原文片段限量展示但完整校验，错误定位不改变原批次 |
| `web/app.mjs`、`app.css`、`index.html`   | 统一星空工作区、详情与列表；时间未知不猜测；来源完整性始终标为声明；手机工具抽屉、焦点循环、标签键盘操作与减少动态效果         |
| `scripts/check.mjs`                      | 除语法和资源检查外，检查重复 ID、缺失的标签目标和脚本引用，避免界面与事件绑定脱节                                              |

所有标题、内容、证据、引用与来源声明均使用文本节点或 Canvas 文字显示。备份没有可执行操作。编辑表单不执行导入内容，手动关系需要用户选择端点、类型与依据。新增回归覆盖了详情和来源中的恶意标记、无效备份不变性、本机存储失败、删除联动、来源身份冲突、历史大小保留以及大文本片段定位。

交互阶段复测：`npm run check`、`npm test`、`npm run test:e2e` 和 `npm run build`。最终执行数量与结果随交付 PR 记录，未执行的浏览器不计入通过范围。浏览器合成大图用例为 10,000 个节点、9,999 条边，验证文件导入、搜索定位和完整导出；另有 10,000 节点剪贴板粘贴用例。它们不是最大规模或真实移动设备的帧率认证。

在本次 Node.js 24.22.1 容器中的单轮布局模块测量如下。每组使用合成链式关系，分别测量初始化与 20 次迭代；不包含浏览器消息复制、Canvas 绘制和图谱导入，不能换算为页面帧率。

| 节点 / 关系     | 初始化  | 20 次迭代  |
| --------------- | ------- | ---------- |
| 1,000 / 999     | 7.6 ms  | 50.1 ms    |
| 10,000 / 9,999  | 20.9 ms | 204.9 ms   |
| 50,000 / 49,999 | 80.4 ms | 1,344.7 ms |

仍存在的边界：快照有保留上限；浏览器存储配额与清理策略由浏览器决定；存储和备份未加密；多页面提醒不提供并发锁；完整备份中的图谱复制、历史和序列化仍有主线程开销；该阶段尚未验证 Firefox、WebKit、真实移动设备及协议上限的全功能操作；CI 与生产部署由后续工程阶段处理。
