# 本地主题包（0.5.0）

主题包用于用户主动整理并下载记忆，再自行交给其他服务。运行时不调用模型、不自动上传、发送或写入剪贴板。不新增运行时依赖。

## 创建和预览

在“主题包”页填写名称，可按关键词、完整标签、记忆类型和确认状态同时筛选。关键词复用工作区的 ID／标题／正文／标签搜索；完整标签区分大小写，建议列表最多显示 100 种，仍可输入其他完整标签。“使用工具栏当前筛选”复制已有关键词、类型和状态，不改变原工作区筛选。

起点包括筛选匹配与手动加入的记忆。可沿原图已有关系双向扩展 1／2 层，扩展项可能不匹配筛选，每条显示起点 ID、真实关系键和层数。不会以相似度补关系。按标题选择器手动加入，同名记录用类型和稳定 ID 区分；从包中移除的 ID 不再参与扩展或成为路径中间点，可通过选择器明确加入回来。

点击“预览／更新差异”后才允许保存和导出。预览按 12 项分页，可逐项核对将导出的记忆、包内关系、不导出的跨包／失效关系、增量差异及检查线索。记录标题、ID、来源、原始确认状态和完整原字段均可查看。关系必须两端都在包内，保留原类型、方向、依据、来源和原有 ID；跨包边只提醒，不自动带入另一端或改边。

## 保存和增量更新

配置与基线保存在独立 IndexedDB `memory-galaxy-topic-packs`，不进入记忆、快照、操作历史、MGP 导出或原有完整备份。每个配置包含筛选条件、手动加入／移除 ID，以及记录、关系、相关来源声明的 SHA-256 指纹；不复制旧正文。清工作区缓存保留配置，清浏览器站点数据会丢失配置。本轮不提供配置跨设备同步或专用备份；最多 100 个有效配置。

“保存配置与本次基线”需确认，会主动推进比较基线，随后需重新预览；若要保留本次增量，请先导出再保存。保存基线不代表已导出，更不表示其他服务收到文件。保存事务完成后才反馈成功，失败保留草稿和旧基线。保存期间禁止重复操作并提醒刷新；同一配置使用事务内版本比较，旧标签页不能静默覆盖新版本或复活已删配置。其他页面的更新不自动丢弃本页草稿。

载入既有配置后重新预览，以稳定 ID／原关系键区分新增、修改和移出。改名仍是同一个 ID 的修改；来源声明变化单列。无显式 `source_id` 的记录还比较其默认来源 ID。移出指离开当前主题包，不等同原图删除。基线不存旧正文，因此不编造旧值或伪装成字段级历史。未再出现的手动加入 ID 会提醒，配置仍保留该 ID。

## 文件格式

完整 JSON 为 `memory-galaxy/topic-pack/1`，增量 JSON 为 `memory-galaxy/topic-pack-delta/1`，均为独立封装，不能当 MGP 直接导入。MGP 1.0／1.1 和现有备份协议未变化。原始记忆、关系及所需来源声明按原字段保留，包括可选字段、扩展与来源追溯；不填日期、不把未知改为已确认。全图扩展、墓碑、快照、个人回顾状态及未选记录不导出。

完整包的 `fingerprint` 是当前记录指纹基线的摘要，不包含生成时间或标题。增量包提供 `base_fingerprint`、当前 `fingerprint`、新增／修改的原记录、移出 ID／关系键及来源声明变化，且标注需要此前对应完整包。变化关系所需的未变端点放入 `context_nodes`，不重复列为新增；预览、检查和实际输出使用同一范围。当前默认来源在包头保留，其他未变来源依赖此前基线。原始来源 `completeness` 只是原声明，包头明确说明这是所选子集，不冒充完整来源导出。

Markdown 将原文和原始元数据分开置于代码区，保留原文字串、字段和换行；依据原文的最长反引号串调整围栏，标题转义。生成时间只表示本机生成文件的实际时间，不是记忆日期。资料和扩展字段明确标记为不可信内容，不应被接收方当系统指令。

## 下载前检查

每次下载都需要确认，包括零命中情况。来源线索复用记忆体检规则，另检查被导出关系的来源；只提供建议，不补来源或脱敏。敏感检查扫描本次导出的原记录、扩展字段、来源声明和标题，提示邮箱、手机号、身份证、令牌／私钥格式及隐私、密码等关键词。提示只列记录 ID、字段路径及规则，不在提示中重复匹配值。

这是启发式本地检查，可能误报和漏报；没有命中不代表可以公开。只有用户能决定是否交给其他服务。确认只发起浏览器下载，不能证明操作系统已写盘或对方已收到；导出不自动推进基线。图谱或配置变化会使预览失效，晚到的分析结果不会重新启用旧导出。

## 验证范围

新增 21 项规则／格式／只读性测试，覆盖多条件筛选、关系扩展与移除、来源保留、同名 ID、指纹与默认来源变化、完整／增量实际范围、端点上下文、Markdown 围栏、敏感扫描、损坏配置及 10,000 条记忆。

新增 17 项浏览器场景，检查下载内容、原备份不变、配置刷新恢复、真实编辑后的增量、原生 IndexedDB 保存失败／提交前反馈／并发版本保护／删除保护、损坏记录、Worker 失败与晚到结果、10,000 条分页，以及 390×844、844×390、1365×900 视口操作。实际通过情况以本轮 PR 与 Actions 日志为准，套件数量不代表已执行通过。

全部数据为明确的虚构测试数据。手机视口／触摸模拟不是真实 iPhone 或 Android 硬件实测。没有本轮私人记忆或真实 AI 导出文件；未验证实体设备键盘、动态地址栏、系统断电／浏览器崩溃的磁盘行为及协议上限设备帧率。敏感线索不能证明无泄漏，来源声明也不等于事实核验。

本地执行上述 17 项浏览器场景时，Chromium 均在启动阶段遇到 `socket() failed: Operation not permitted`，本地结果为 17 项启动失败，没有完成页面断言；未记作功能通过。完整浏览器矩阵由仓库现有 GitHub Actions 执行，另使用独立浏览器手工核对。
