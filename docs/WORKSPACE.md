# 星盘与本机工作区

## 浏览星图

星图使用导入或手动创建的关系计算布局，不会根据距离、标题相似度或星团分组新增关系。推测关系用虚线表示，依据类型仍来自原始数据或用户填写。

- 按类型、记录来源或真实连通关系分组，也可以关闭分组。切换分组时未固定的节点会重新布局，固定节点保持原位。连通关系分组只计算已有边，孤立节点独立成组。
- 拖动空白平移；滚轮或双指缩放；双击或点击「适配星图」查看全部筛选结果。
- 拖动星星会固定其位置。详情中的「释放固定」允许布局继续移动该节点。
- 点击星星高亮相邻节点及已有关系；详情中的关系按钮可定位另一端、单独高亮、编辑或删除关系。
- 搜索匹配标题、正文、标签和稳定 ID。选择结果或按 Enter 定位第一条结果；类型与状态筛选同时作用于星图、列表和记忆时间线。

星图支持方向键平移、加减号缩放、Home 适配和 Escape 关闭选择。视图标签支持左右方向键、Home 和 End。记忆列表提供相同数据的键盘浏览入口，正文与来源使用普通文本显示。系统启用减少动态效果时，布局默认只显示初始和最终位置；可手动调整动画设置。

布局在 Worker 中运行，主线程保留 Canvas 渲染。空间网格按单元聚合排斥力，避免密集单元逐对遍历。绘制按视野裁剪，并限制普通连线、选中节点关联线和标签数量；密集星体按屏幕单元减少重复绘制。同屏最多绘制约 8,000 颗星、12,000 条普通连线及 3,000 条选中关联线。页面显示实际绘制数量；未绘制的数据仍保留在工作区、分页列表、详情和导出中。

这些策略控制计算与绘制开销，不保证所有设备或协议上限下的帧率。Worker 不可用时显示初始布局并明确提示，可继续使用列表和编辑功能。

## 编辑与来源

添加第一条自己的记忆时，会从空白图谱开始，示例节点及其来源不会混入。示例内容只用于浏览；导入或新建工作区后可编辑真实数据。

节点可编辑标题、类型、正文、标签、状态、引用及敏感标记。现有稳定 ID 不可更改；新节点可指定未使用的 ID，或由浏览器使用随机数生成。删除会保留 MGP 墓碑，节点删除也会删除附属关系。已删除 ID 不能通过「添加」静默复用；可通过导入冲突确认或快照恢复。

关系可手动新增、编辑和删除。起点与终点通过标题或 ID 搜索，并从结果中明确选择；每条结果显示标题、类型和短 ID，短 ID 碰撞时展开完整 ID。同名记忆不会自动合并，也不会按标题决定端点。关系内部仍保存原稳定 ID。端点必须存在，必须填写依据，并明确选择明确、推测或规则关系。旧版三元组关系在第一次编辑时获得稳定 ID，原三元组保留删除记录；后续端点或类型变化保持该 ID。

手动编辑记录本机来源、更新时间和 revision，同时保留原有 provenance 与引用。编辑外部记录时，原引用保留在原来源的追溯条目中，编辑表单的引用栏留空，供本次手动编辑填写；不会把外部引用改挂到本机来源。若导入数据已占用本机来源名称且声明不同，会使用另一个来源 ID，避免替换原声明。来源页展示覆盖范围、完整性与导出时间，均标明未经独立验证。

记忆时间线使用记录的 `updated_at`，不是事情发生或首次创建的时间。缺少时间的记录单列，不猜测日期。本机操作时间线只记录实际执行的导入、编辑、删除和恢复等操作，最多保留 200 条；重新打开已保存的工作区不会虚增恢复事件。

## 保存、快照与恢复

编辑表单中的内容先属于未应用草稿；「应用更改」才将它们放入当前工作区，不代表已经写入本机。页头与工具栏中的「保存到本机」会把已应用的图谱、历史和视图写入同源 IndexedDB；也可以主动启用自动保存。只有事务提交成功才显示「已保存到本机」。保存进行中禁用重复提交；已保存且没有变化时不重复写入。保存过程中继续修改会保持未保存提示，不会把较新的修改误标为已落盘。自动保存会在修改后合并短时间内的写入。存储和下载文件均未加密，`sensitive` 仅是标记。

旧版 `memory-galaxy-mgp-v1` localStorage 缓存会在没有新版保存时读取。主动保存后迁移到 IndexedDB，旧缓存暂时保留；清除缓存会删除这两处保存，并关闭自动保存。清除缓存不清空当前页面里的工作区。

保存失败会提示错误，内存数据仍保留。读取到损坏缓存时原内容也会保留，自动保存关闭；覆盖前需再次明确确认。多个页面之间通过 BroadcastChannel 提醒存储变化，并暂停后收到通知的页面的自动保存；再次覆盖需确认。此外，保存和清除操作会在同一个 IndexedDB 读写事务中核对保存版本；即使通知缺失或多个页面同时写入，过期页面也不能静默覆盖。冲突会保留内存图谱、关闭自动保存，并要求确认后重新读取保存版本。清除后只保留不含图谱的随机版本标记，防止旧页面恢复已清除的缓存。旧版 IndexedDB 记录在主动保存时补上版本标记，格式不变。此机制不是图谱的多人协作或自动合并；升级前仍打开的旧版页面不支持版本检查，应刷新后再编辑。关闭编辑表单会先确认是否放弃未应用的修改。未应用草稿、未保存工作区、进行中的保存及待导入文本会注册刷新和离开的风险提示，包括切回示例但快照仍未保存的情况。浏览器是否显示原生提示仍受其用户交互要求及移动平台限制；这不等同于崩溃恢复。

每次替换图谱前保留修改前快照，也可创建命名快照。自动快照标题标明操作前状态；重命名时使用编辑前的标题，操作记录则使用编辑后的标题。既有备份中的历史标题不会被重写。最多保留 12 份、图谱 JSON 总计 16 MiB；超出任一限制时移除最早的快照，并提示需要长期保留时下载备份。快照只保存图谱，恢复快照前会保留当前图谱。「撤销上次修改」使用最近一份修改前快照。快照随本机工作区一起保存；未保存时刷新不会保留。

「新建空白」和「查看示例」在替换真实图谱前需要确认，并保留当前图谱的快照。之后可从快照返回。

## 导出与完整备份

| 操作          | 内容                                                             | 恢复方式                                             |
| ------------- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| 导出星盘 JSON | 当前 MGP 图谱、来源与删除记录                                    | 使用普通导入，预览增量差异与冲突                     |
| 下载完整备份  | 当前图谱、历史快照、操作记录、分组与标签设置、节点坐标与固定状态 | 使用「恢复完整备份」，先校验和预览，再确认替换工作区 |

下载使用紧凑 JSON，避免排版空白使接近大小上限的文件无法重新导入。普通 MGP 输入与图谱仍限制为 12 MiB；完整备份限制为 48 MiB，并分别校验图谱、快照、历史和视图。完整备份不是 MGP 增量文档，不会经普通导入自动替换整个工作区。

完整备份格式为 `memory-galaxy/backup/1`，根字段包括 `format`、`created_at`、`graph`、`demo`、`snapshots`、`events` 和 `view`。未知格式、未知字段、无效引用、危险对象属性、重复快照身份、超量历史与无效坐标都会阻止恢复。`view` 包括 `clusterBy`、`showLabels`、`animate`、`positions`；每个位置包含已存在节点的 `id`、有限的 `x` / `y` 与布尔 `pinned`。恢复前的真实图谱会保留为一份修改前快照，仍受历史保留上限约束。完整备份的历史和视图会替换当前历史与视图，若需长期保留恢复前的整个工作区，应先下载其完整备份。

备份读取和校验在 Worker 中运行；取消、超时、格式错误及未确认预览都不修改当前工作区。内容一律视为数据，备份内没有可执行脚本或远程资源字段。

## 大批次导入

粘贴大批次时，在浏览器排版前接收完整剪贴板文本并交给现有导入流程。超过 65,536 个字符的原文只展示有上限的只读片段，完整内容参与校验、冲突预览与导入；错误行列仍对应完整原文，点击错误会显示对应片段。需要修改大批次时，重新粘贴或选择修正后的文件，不能将截断片段误作整批提交。

小批次仍可在预览文本框直接修改并重新校验。大型图谱建议使用文件导入，以减少浏览器输入控件的开销。

## 导入冲突审查

默认逐项审查，不替用户选择。每项冲突直接展示字段路径、变化类别、当前值和采用导入后的值；新增、移除与不同值使用文字区分。节点和关系的预览沿用实际增量合并逻辑，未出现的可选字段不会误显示为删除，跨来源的引用与 revision 按协议处理，原有来源追溯仍保留。

完整当前记录与原始导入 JSON 放在可展开详情中，展开时才渲染。底部集中显示冲突总数、待处理与已处理数量和确认按钮。修改选择会重新校验；尚有冲突、依赖未满足或工作区已变化时不能确认。取消不修改图谱或本机保存。

## 当前标签页的浏览状态

刷新时尝试恢复视图标签、原始搜索词、类型与状态筛选、列表和时间线页码、选中节点、关系页码及图谱缩放和平移。状态仅写入当前标签页的 sessionStorage，不包含记忆正文、图谱、快照或表单草稿，也不扩展 MGP 或备份协议。独立打开的新标签页使用默认浏览状态；浏览器复制标签页时可能复制初始 sessionStorage，之后仍各自独立。

存储不可用、内容损坏、未知版本或失效选项会回退到默认值；节点不存在时清除选择，页码按当前结果范围收敛。浏览状态恢复不等于保存记忆；未保存数据仍需先应用并保存。关闭标签页后，不承诺保留这份临时状态。

## 记忆回顾与体检

回顾页复用现有查找、类型与状态筛选。默认按提供的更新时间查找旧记忆，并明确列出本机状态与实际关联记录的理由；时间缺失不推断新旧。支持收藏、跳过 7 天、标记已回顾及重新待回顾。状态独立自动保存至当前浏览器，只有事务完成才反馈成功，不修改原图谱或保存版本；原有 MGP 导出和完整工作区备份不包含这些个人状态。清除工作区缓存会保留它们，回顾页提供单独确认清除。

体检检查整个当前图谱，分别展示字面重复线索、孤立节点、来源追溯不完整及待核实旧记录。只有查看与核对入口；需要处理时进入已有详情，由你自行编辑或确认删除。时间阈值依据 `updated_at`，不当作发生或确认时间；同名和同正文只作为线索。详细规则、保存边界和验证范围见 [0.4.0 验证记录](VERIFICATION-0.4.0.md)。

## 主题包

0.5.0 新增独立的本机主题包配置与稳定 ID 指纹基线，支持完整及增量 Markdown／JSON 手动下载。其配置与基线不进入原始记忆或现有备份，保存与下载分别确认；来源与敏感线索检查不会自动修改记录。具体筛选、关系范围、差异语义、格式与验证边界见 [主题包说明](TOPIC-PACKS.md)。
